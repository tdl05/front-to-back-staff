## Front2Back Miami Staffing

A static landing page for Front2Back Miami event staffing, built with HTML, CSS, and JavaScript.

## Vercel Deployment

This project can be deployed on Vercel as a static site. The `vercel.json` file is configured to serve `index.html` using `@vercel/static`.

To deploy:

1. Install the Vercel CLI: `npm install -g vercel`
2. Log in with `vercel login`
3. Run `vercel` in this directory

If you connect the GitHub repo to Vercel, it will automatically deploy on each push to `master`.
